PANDUAN TAMBAH BAHAN TANPA MENGUBAH index.html

1. Upload index_HSAH_flip_catalog.html ke GitHub dan namakan sebagai index.html (gantikan index.html lama hanya selepas backup).
2. Upload education-data.json ke root repo yang sama.
3. Simpan bahan dalam assets/education/ (contoh assets/education/ot/poster-01.jpg).
4. Dalam education-data.json, pilih id buku yang betul dan masukkan laluan fail di bawah bahan.poster / bahan.pdf / bahan.video. Untuk pautan web, guna URL penuh https://.
5. GitHub Pages ialah hosting statik: tiada panel admin atau muat naik terus dalam laman; fail perlu ditambah ke repo.
6. Uji pada preview/staging sebelum menggantikan laman sebenar. Kekalkan salinan index.html asal.

Nota: laman masih mempunyai kandungan asas terbina dalam jika education-data.json tiada/gagal dimuatkan. Katalog ini menambah atau mengubah pautan bahan untuk buku sedia ada.
